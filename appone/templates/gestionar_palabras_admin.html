Acerca de los Productos

Productos

Los productos definidos aquí permiten personalizar las licitaciones priorizadas que se muestran a los usuarios. Como administrador, al definir productos, estás indicando las categorías o áreas de interés principales que se utilizarán para filtrar las licitaciones extraídas de Mercado Público. Estos productos se combinan con las preferencias de cada usuario y los datos de los clientes asignados para generar un listado de licitaciones relevantes, optimizando la búsqueda y reduciendo la cantidad de licitaciones a revisar.

Ejemplo: Si defines productos como "construcción, salud", el sistema priorizará licitaciones relacionadas con esos sectores para todos los usuarios bajo tu administración.
